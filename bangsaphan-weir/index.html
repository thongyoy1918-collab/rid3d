01 / ฝายทดน้ำทำอะไร

ฝายยกระดับน้ำในคลองบางสะพานให้สูงถึงสันฝาย +13.50 ม.รทก. น้ำส่วนที่เกินจะไหลล้นข้ามสันไปเอง ส่วนบานระบาย 2 บาน (6.00 × 3.33 ม.) ใช้ระบายน้ำหลากและควบคุมระดับ และช่องระบายทรายฝั่งใต้ใช้ล้างตะกอนหน้าฝาย

02 / น้ำล้นสันฝาย

อัตราการไหลข้ามสันคำนวณจาก Q = C·L·H1.5 โดย L = 39.40 ม. คือความยาวสันฝาย H คือความลึกน้ำเหนือสัน และ C ≈ 2.1 เมื่อน้ำท้ายฝายสูงจนท่วมสัน อัตราการไหลจะลดลงตามสัดส่วนการจม

03 / น้ำไหลใต้บาน

เมื่อยกบานขึ้น a เมตร น้ำพุ่งออกใต้บานตาม q = C·W·√(2gy) (C ≈ 0.61, W = 6.00 ม.) เครื่องกว้านยกบานได้ราว 0.30 ม./นาที ถ้ายกบานพ้นผิวน้ำ การไหลจะกลายเป็นแบบฝายสันกว้าง

04 / น้ำกระโดดในแอ่งน้ำนิ่ง

น้ำที่ไหลลงจากสันมีความเร็วสูง (Froude > 1) แอ่งน้ำนิ่งยาว 20 ม. ที่ระดับ +8.00 ทำให้เกิดน้ำกระโดด ความลึกหลังกระโดด y₂ = y₁/2·(√(1+8F₁²) − 1) ถ้าระดับน้ำท้ายฝายต่ำกว่า 8.00 + y₂ น้ำกระโดดจะหลุดออกนอกแอ่งและกัดเซาะท้องคลอง

05 / ระดับน้ำท้ายฝาย

คำนวณจากสมการแมนนิงของลำน้ำท้ายฝาย (n = 0.035, ความลาด 0.001) เพื่อหาความลึกน้ำจากปริมาณน้ำที่ไหลผ่าน ค่าเหล่านี้เป็นค่าสมมติเพื่อการเรียนรู้
